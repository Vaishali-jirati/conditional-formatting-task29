## Basic Conditional Formatting (Retail Sales Dataset, Excel)

## Overview
Applied basic conditional formatting rules to highlight top and bottom values in the Retail Sales dataset using Microsoft Excel, improving overall report readability.

## Files
- `conditional_formatting.xlsx`: Formatted Excel workbook containing:
  - `Retails data`: Original raw dataset sheet.
  - `formatting`: Sheet with conditional formatting applied to the `Total Amount` column.
  - `rules`: Detailed documentation of the rules used.

## Setup
- Tool: Microsoft Excel
- Dataset: Retail Sales Dataset

## Applied Rules & Deliverables
1. **Top 5 Highest Sales:** Highlighted the top 5 highest revenue transactions in the `Total Amount` column using **Light Red Fill with Dark Red Text** to instantly spot key revenue drivers.
2. **Bottom 5 Lowest Sales:** Highlighted the bottom 5 lowest transactions using **Green Fill with Dark Text** to easily track low-performing sales or outliers.

## What I learned
- How to use Conditional Formatting rules dynamically instead of manual coloring.
- Using visual cues (color scales and top/bottom rules) to instantly draw attention to key data points and outliers in large reports.
